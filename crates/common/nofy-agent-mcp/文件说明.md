# 入站 MCP 适配器

`src/lib.rs` 使用官方 rmcp SDK 实现 stdio 与无状态 Streamable HTTP Server；工具由客户端操作目录和同一 Schema 生成。stdio 的 stdout 仅输出协议消息；HTTP 每请求验证并传递 Bearer 身份，绝不使用进程固定管理员令牌后备，Origin/Host 由 SDK 校验。资源限制在契约、登记预设、托管源码工程和源码归档分块。请求取消只结束等待，业务取消必须显式调用 `nofy_run_cancel`。适配器不执行上传源码，不提供任意 URL 代理或凭据正文工具。

tools/list 和初始化说明指向统一装配指南；schema 返回公开参数与步骤，调用方无需读取框架实现源码。
