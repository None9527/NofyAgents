# 框架协议测试夹具

CLEAN5a从codegen迁入common；所有Rust源、原SSE帧、包名/API保持原字节，旧路径不留转发。它是测试支持而非Agent运行依赖，迁移须回归契约与实际Host，不能把搬目录当作最终旧树清理完成。

本包仅生成目标Host契约/恢复测试使用的三种Chat Completions SSE帧，不包含Agent、模型实现、ACP/stdio/PTY宿主、子进程管理、环境覆写或旧产品测试入口。夹具中的模型名与固定usage是测试输入，不是真实服务或用量证据；真实模型验收独立使用用户配置连接。

- Owner：框架协议测试维护者。
- Read When：实现确定性流式协议或Host恢复用例时。
- Update Trigger：SSE帧、工具调用参数、保留函数或依赖边界变化。
- Validation：`cargo test --locked --offline -p nofy-test-support`、完整Host回归与`scripts/verify-framework-boundaries.py`。

| 文件 | 职责 |
|---|---|
| src/lib.rs | 仅导出sse模块，禁止unsafe |
| src/sse.rs | 三种帧生成函数、无名SseEvent数据帧及Axum转换 |
| tests/sse_contract.rs | 空白/Unicode/空文本、调用原始参数和帧终止顺序；Axum线编码一致性 |

普通/构建内部依赖仅本包自身，直接第三方依赖仅Axum和serde_json；测试代码另用的Tokio/futures-util放dev。CLEAN4d在原实现的三项契约通过后保留同一帧生成逻辑，删除十二个旧宿主/产品服务模块，无旧API别名。Host仍实际需要tty-utils执行原生进程组取消与隔离，该中立安全能力不等于本次淘汰的PTY测试宿主。全源码树和完整唯一预设仍需后续交付。
