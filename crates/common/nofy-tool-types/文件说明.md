# 工具定义与描述类型

本包只描述工具身份、展示信息、调用参数和模型工具定义，不拥有任务执行、子Agent预设、默认提示词或产品参数兼容解析。业务能力通过框架声明、模块与外部制品提供。

| 文件 | 职责 |
|---|---|
| `src/definition.rs` | 模型工具函数定义与JSON Schema参数 |
| `src/types.rs` | 工具描述、参数类型和显式校验错误 |
| `src/ext.rs` | 不序列化的类型化运行扩展数据 |
| `src/schema_utils.rs` | 描述展示使用的有损平面参数投影，不替代原始JSON Schema验证 |
| `src/lib.rs` | 上述中立契约的唯一导出 |

CLEAN4b删除旧task DTO、内置Explore/Plan/General预设、提示词模板feature和lenient任务参数模块，没有在其他包提供同名兼容导出。schema_utils保留通用Schema到参数描述的投影，不赋予隐式业务语义。验证使用`cargo test --locked --offline -p nofy-tool-types`及上层Host/Runtime回归；完整旧源码树清理与唯一编程Agent预设仍是独立未完成项。
