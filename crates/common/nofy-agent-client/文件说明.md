# 共用开发客户端

`contracts/operations.json` 与 `contracts/contracts.schema.json` 是打包在 crate 内的统一操作目录和契约，手册同步相同内容。`src/contract.rs` 负责输入验证、精确版本与结果信封；`transport.rs` 固定内核路由、禁用重定向并传递调用身份；`operations.rs` 和 `projects.rs` 将操作映射到原生控制面及共用源码引擎。客户端不拥有 Agent 执行循环、权限裁决、预算或恢复状态。凭据正文只能经过专用私有 CLI 入口注入，不进入普通 MCP 工具输入。

repositories.rs 统一仓库操作与缓存源码解析；构建/导出获取已缓存的精确源码，源码编辑保留引用。

src/guides.rs 及 guides/operation.rs、factory.rs、preset.rs 生成机器可消费的装配指南；契约 0.6 的 schema 支持操作、工厂、预设和固定模块包，错误含具体字段与恢复步骤。describe 默认精简目录，agent.apply 不重复返回整份发布实现，run.inspect 默认状态视图；完整目录/发布/运行使用各自显式参数读取。
