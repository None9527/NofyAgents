# 中立声明模块

| 文件 | 职责 |
| --- | --- |
| `src/prompt.rs` | 可版本化Prompt文档、变量、来源与渲染预览；Host隔离执行使用同一引擎 |
| `src/rules.rs` | 明确正文/来源的规则上下文，不读取用户目录或产品配置 |
| `src/skills.rs`、`src/skills/definition.rs` | 声明Skill定义、条件激活、列表、调用来源与工厂 |
| `src/skills/render.rs`、`substitution.rs` | 通用参数/包路径替换与明确资源上限，不继承厂商别名 |
| `src/skills/execution.rs`、`scope.rs` | 子Agent执行、父权限收窄、原根预算/审批与恢复；不使用旧宿主 |
| `src/bindings.rs` | 显式绝对目录绑定；拒绝冲突，不发现宿主目录或授予文件系统权限 |
| `src/scope_program.rs` | artifact作用域资源、编译器、显式执行器及目录/子集/取消/字节边界 |
| `src/scope_program/engine.rs`、`json.rs` | 有界纯程序及无损JSON桥，无隐式IO或业务派发 |
| `src/scope_program/skills.rs` | `tool.skills_scoped`的显式作用域资源依赖；复用同一技能执行路径，不引入第二套主循环 |

本包只依赖公共运行时与工具协议及通用算法库。新能力仍由系统声明与Loader装配；新增包不等于完整框架、资源发现或编程预设已完成。

Skill声明包含`name/description/path/body`、可选包`package:{name,version,root?,data?}`、有界字符串`metadata`、条件`paths`和调用/执行选项。包来源不引入产品插件管理器；路径只作显式来源、替换和匹配，不扫描HOME或读取正文。`user_invocable`和`disable_model_invocation`独立控制人工/模型调用；人工调用仍要求运行时签发且参数一致的证明。

参数支持`$ARGUMENTS`、`$ARGUMENTS[N]`、`$N`及`${SKILL_DIR}/${SESSION_ID}/${PACKAGE_ROOT}/${PACKAGE_DATA}`；不提供厂商别名。参数最多64KiB，默认替换输入/输出各1MiB、工作量64MiB，Host可进一步收紧；失败不返回部分正文。列表按`max_listing_bytes`计真实字节，范围256～262144，默认65536；省略项显式计数，不截断正文。正文合计4MiB、全部字段8MiB、最多1024条Skill及1024个条件路径模式；一次激活最多200万次模式/路径比较，超额显式失败。条件匹配使用有界自动机，不使用权限通配的递归匹配器。

作用域授权词汇、工具及参数含义由外部程序定义；本包不再实现Read/Bash/MCP等旧权限语言、工具分类或包装器特权。作用域只能收窄父权限，不能替代父级审批。Host使用受限辅助进程执行程序，SDK直接调用Program属于进程内执行。系统可变能力的导入、依赖锁定、运行中切换与生命周期由Host/Loader承担；本包不是第二套Agent或独立控制面。

CLEAN4e-M2已由默认Host的同一Loader注册resource.scope_program：源码和可选参数Schema仅来自artifact，参数/目录/限制与执行器身份进入内容锁定。tool.skills_scoped的scope字段为资源槽名字符串，并显式声明同名Resource依赖；工厂修订为2:artifact-scope，旧对象配置不回退解析。作用域是编译依赖，不混入子Agent执行模块；原模块类型/数量校验不放宽。旧permission源码及tree-sitter-bash直接依赖已删除。

程序经同一SkillScopeCompiler组合现有技能，不替换父权限。返回唯一子集、目录绑定、取消前后检查和编码字节上限由内核保留；动态JSON先预算再物化，u64不转float。Executor须显式提供且可用，无默认进程内回退。默认Host使用nofy.scope-program-evaluate/v1受限辅助进程；SDK进程内运行不是OS隔离证明。发布后新运行装载新代码、待审批旧运行保持原版本及回滚有独立用例，不等于运行中作用域热切换或完整编程预设完成。契约见docs/architecture/scope-program-contract.md，测试为tests/scope_program.rs。
