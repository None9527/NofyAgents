该可选 crate 将外部配置绑定到真实工具执行边界。工厂构建负责校验和装配，网络、凭据解析和进程启动发生在实际调用时；执行能力由宿主显式安装的资源约束。

| 路径 | 职责 |
| --- | --- |
| lib.rs | 工具目录装配、JSON输入上限和Schema校验、输出映射 |
| config.rs | 可序列化工具契约、输入映射和公共Schema |
| ../nofy-agent-runtime/src/artifact.rs | 共享有界UTF-8制品、路径/摘要及纯resource.artifact工厂的唯一归属；执行器旧位置已移除，无兼容导出 |
| resources.rs | 凭据与进程环境的可信宿主资源契约；load_preserving_path保留显式程序调用位置，避免破坏venv/工具链前缀，同时保留每次调用前字节检查；既有load语义不变 |
| http.rs、http/connection.rs | HTTP工具及版本化连接资源，沿实际客户端调用执行 |
| declarative.rs | 系统声明到连接资源和关联工具工厂的装配 |
| process.rs | 宿主许可程序/解释器、JSON stdin、超时/输出限制及进程调用 |
| hooks.rs | 将原工具执行边界装配为Hook handler |
| code.rs、code/execution.rs、code/rhai.rs | 可选Rhai源码方法、显式Executor/Request及trusted SDK实际拥有者；纯构建和同步VM入口分离，Host必须在隔离后才调用VM |
| tests/executors.rs | 共享测试资源、原入口及执行器验收 |

默认无额外feature；rhai为显式可选项，旧产品nofy-sandbox桥接已删除。ProcessEnvironment::install保留原宿主路径身份；bind使用可信宿主提供的逻辑运行时身份，不将临时目录混入版本。nofy-agent-host负责制品仓库、显式本地/锁定环境与隔离helper，复用原ProcessToolFactory/dispatch；本包不引入Landlock等宿主隔离依赖，不安装/重建外部依赖。用户安装的文件可独立更新，Host本地环境每次准备程序时重新读取，不要求用户提交依赖摘要；旧运行的预算/效果记录独立保存。

code/session.rs 将 SessionPolicy 接到既有隔离纯 JSON Executor；code/rhai.rs 的时间入口与直接/Fn 调用均按纯执行边界处理。普通源码变更不要求改 Rust 工厂。
