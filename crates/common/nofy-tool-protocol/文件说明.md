# 工具身份与能力元数据

本包是声明式Agent框架的中立叶子契约，不提供Hub或第二套执行传输。只有ToolId、ToolCallId、IdError及ToolCapabilities、StreamingSpec、ToolScope；执行、输出、取消和规范错误由tool-runtime拥有，生命周期由框架Hook模块负责。

- Owner：工具契约维护者。
- Read When：使用工具定义/调用身份或能力声明时。
- Update Trigger：身份验证、能力Schema或依赖边界变化。
- Validation：`cargo test --locked --offline -p nofy-tool-protocol`和`scripts/verify-framework-boundaries.py`。

| 文件 | 职责 |
|---|---|
| src/lib.rs | 仅导出中立契约 |
| src/ids.rs | 工具定义与单次调用身份、构造/Serde验证、UUID v7 |
| src/capabilities.rs | 流、取消、并发、只读、版本、预算与访问范围元数据，未知字段拒绝 |
| tests/identifier_validation.rs | 合法/非法工具ID、接口和Serde一致性、调用身份 |
| tests/capabilities.rs | 能力往返、明确默认值、旧Hub及未知字段拒绝 |

普通/构建依赖不得含其他内部包，serde_json仅供测试。元数据不是权限、调度、领导者路由或内存隔离保证。CLEAN4c删除旧Hub的会话/连接/注册/通知/输出/错误协议及对应测试，无兼容别名；尚未完成整个旧源码树清理。
