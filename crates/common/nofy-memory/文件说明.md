## CLEAN1 当前边界

记忆请求/回执与MemoryService归属`crates/common/nofy-memory-types`，引擎与调用方直接依赖该协议，不再经旧工具包导出。引擎普通依赖已切断旧Agent、工具全集、产品配置、登录/HTTP包装与遥测；`src/config.rs`拥有索引、搜索、时间衰减、MMR和敏感类别。只支持显式temporal_decay，不保留recency_decay兼容参数。`MemoryStorage::new`必须显式提供根目录，不发现HOME或旧设置。

`src/embedding.rs`接受明确端点、模型、尺寸与外部HTTP客户端；认证、超时和重试由上层管理，不默认使用旧代理/登录或产品头。响应有8MiB上限，并验证批次条数、索引、尺寸与有限浮点数，不用过滤坏元素来伪造有效向量。协议测试通过本机真实HTTP验证；未宣称Host已完成声明式embedding资源与预算接入。

`scripts/verify-framework-boundaries.py`核对Cargo的真实普通依赖闭包，覆盖默认与agent-runtime两种装配。默认仅含本包、独立记忆协议、SQLite日志模块；启用声明装配额外带入中立运行时/工具契约。依赖切断不代表全部记忆代码已净化：现有迁移备份、旧路径启发式及原数据模型仍须按目标职责审核，整个Host与旧源码树尚未清理完成。

Host 的普通 resource.memory 和显式学习 resource.memory_learning 使用同一规范引擎、持久撤销和逐工作接纳；学习资源显式启用成功回合捕获。以下 B0/B1 仅保留实现溯源，旧产品兼容不构成交付目标。
