# CLI

`nofy` 是统一声明式内核的开发入口。`src/command.rs` 从共用操作目录生成命令树和具名参数；`config.rs` 读取连接 profile 与私有令牌引用；`input.rs` 将 CLI 参数、本地文件和原生 JSON 转为统一操作输入；`output.rs` 原子保存声明/归档并处理等待与事件续读；`main.rs` 连接共用客户端与 MCP Server。CLI 不维护第二套 Agent 配置，不启动旧宿主，不安装或打包用户的外部依赖。源码工程写入采用原摘要/版本检查，避免 CLI 与 MCP 并发覆盖。

repository/module 命令以及 agent module use/unuse 从共用契约生成；--directory 上传客户端源码，--host-directory 明确登记 Host 来源。tests/development/repositories.rs 贯通 CLI、官方 MCP 客户端、目录/Git 与离线导出。
