# Rust 源码工程引擎

codec.rs 定义可移植文件、精确字节摘要、路径和 JSON Pointer；render.rs 处理受限纯声明变换、参数推导与模块内容版本；edit.rs 修改同一声明、依赖及插槽；files.rs 收集和落地本地副本、只打包源码；store.rs 管理内核托管副本和模板目录。CLI、HTTP 与 MCP 共用本库，不执行项目脚本、不安装依赖、不设置源码归档配额。

repository/package.rs 定义模块包及来源；repository/files.rs 采集显式目录源码；repository/store.rs 保存 CAS 目录和不可变共享源码；repository/compose.rs 管理声明引用、参数接线及纯展开。新增 tests/repositories.rs 验证共享版本、端口、冲突和离线导出。

agent.configure 使用同一 CAS 编辑路径更新公开 settings 文件和清单，保留字面参数并清除同一 Source 的临时覆盖。
