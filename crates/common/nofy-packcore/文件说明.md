# 组合数据契约

本包只提供 `PackManifest` 的 JSON 解析、模型与宿主配置平面隔离、服务命名空间及组合冲突检查。`src/lib.rs` 包含契约和对应回归；`Cargo.toml` 声明依赖。CLEAN5c 迁入 common 并移出原 daemon 的内置 file-steward 数据及其专属测试，不带入旧产品入口。

Runtime 的可选 `pack` feature 使用这些类型完成 SDK 绑定；默认 Host 的预设由 System 声明和 Loader 管理，不能把此库视为另一套常驻 Pack 管理器。此库也不是源码归档器，不安装依赖、不承诺环境闭包或参考 Agent 的行为复现。
