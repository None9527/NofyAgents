# Goal 状态模块文件说明

该crate保存原Goal的状态、生命周期、快照和私有制品处理。规划模型、验证器调度和宿主编排由调用方接入；状态模块本身不等于完整规划执行器。

| 路径 | 职责 |
| --- | --- |
| lib.rs | 公共导出、角色模型与共享契约 |
| state.rs | Goal类型、状态编码、Tracker生命周期、快照、默认值及原同步制品文件处理 |
| state.rs内嵌tests模块 | 原状态、恢复、预算、兼容编码及文件行为回归 |
| Cargo.toml | 独立依赖及test-support特性；Unix目录检查使用libc |

保留原公开路径、serde格式、未知状态回退、预算算法与no-follow检查。结构调整按职责和替换边界决定，不使用固定文件行数作为验收门槛。当前能力与实际测试结果见模块化闭环计划。
