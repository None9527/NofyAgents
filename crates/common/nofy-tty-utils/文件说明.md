# 进程生命周期基础工具

中立进程/操作系统基础包，归属声明式框架，不包含TUI、PTY会话、旧Shell或Agent循环。CLEAN5a从codegen迁入common，保留原执行代码、包名和API；收尾仅修正process_scope.rs中的公开文档链接，未改进程逻辑。TTY脱离只是进程启动的一项保护，不等同Host的完整权限、挂载、网络或资源隔离。

| 文件 | 职责 |
|---|---|
| src/lib.rs | std/Tokio命令的TTY脱离、pager环境与进程组操作 |
| src/process_scope.rs | 受管进程组登记、取消和退出清理 |
| src/process_resources.rs | 平台进程内存与CPU资源采样 |
| src/runtime.rs | 共享Tokio运行时工具 |
| Cargo.toml | 纯进程及平台系统依赖，无旧宿主/配置依赖 |

迁移不修改setsid/进程组或取消语义，不引入旧路径重导出；验收原包测试和Host真实进程树。完整执行保护仍由同一个Loader提供，不能以辅助工具代替内核隔离。
