# 记忆

记忆让 Nofy 在新的会话中继续理解你的长期偏好和当前项目约定。界面始终只呈现两个区域：

- **关于我**：跨项目适用的偏好、工作方式和稳定个人事实。
- **当前项目**：只对当前仓库有效的约定、决策和项目事实。同一仓库的不同 worktree 共享这一部分。

记忆默认关闭。启用后，主助手会在需要时检索相关内容，并在每个推理片段开始时使用一份冻结快照；后台更新不会在回答中途改变上下文。

## 启用

在 `~/.nofy/config.toml` 中配置：

```toml
[memory]
enabled = true
automatic_learning_enabled = true
personal_enabled = true
project_enabled = true
```

也可以使用 `--experimental-memory` 或 `NOFY_MEMORY=1` 临时启用。`--no-memory` 和 `NOFY_MEMORY=0` 始终优先关闭记忆。

`automatic_learning_enabled` 只控制后台学习。关闭它以后，明确的记住、纠正和遗忘仍然可用。`/memory on` 与 `/memory off` 只影响当前会话，不改配置文件。

## 四个动作

### 记住

直接告诉主助手要记住什么，并说明属于“关于我”还是“当前项目”。也可以使用：

```text
/remember 所有 Rust 测试优先使用 cargo nextest
```

确认后内容通过统一记忆服务立即提交。成功结果会说明写入了哪个区域，并提供可用于撤销的操作标识。凭据、令牌和其他敏感正文不会被保存。

### 查找与解释

可以自然地询问“你记得我什么”“这个项目为什么采用这一约定”，或让助手搜索某个主题。搜索结果会返回稳定目标标识；解释会同时给出记忆事实、来源、记录时间，以及能否纠正或遗忘。

`/memory` 打开只读浏览器，按“关于我”和“当前项目”列出主题。它展示的是记忆对象，不暴露内部文件路径。

### 纠正

当事实变化时，要求助手纠正已有记忆。纠正必须针对搜索或解释返回的目标及其版本哈希；如果内容已被其他会话更新，系统会拒绝旧版本写入并要求重新读取，避免静默覆盖。

### 遗忘

先查找目标，再明确确认遗忘。遗忘会建立优先级最高的删除记录，使内容在重启、重新整理和重建索引后都不会复活。第一次明确遗忘也会销毁迁移期间保留的可恢复副本。

## 自动学习

主助手只从已经持久化的顶层会话轮次中提取有长期价值的、可被原文支持的事实。短期任务状态、猜测、通用建议和敏感类别会被跳过。子代理不会拥有记忆工具，也不会单独写入自动学习队列。

自动捕获在后台静默运行；正常情况下不会逐轮弹通知，也不会阻塞答案展示。`/flush` 只检查当前轮次是否已经越过持久化和捕获屏障，不会另写一份会话摘要。`/dream` 使用同一个服务整理尚未归档的观察，不创建第二套记忆。

## 安全与可控性

- 注入模型前会进行提示词威胁扫描；可疑指令被替换为阻断标记，原文不会进入提示词。
- 自动整理不能覆盖用户拥有或固定的主题；用户纠正始终优先。
- 正文不会进入遥测。遥测只包含操作类型、范围、耗时、计数和不可逆的会话标识。
- 主助手拥有读写能力；子代理只能获得任务显式提供的只读上下文。

如果记忆未启用，工具会明确返回“记忆未启用”，不会回退到另一种存储方式。
