## 1. 背景

R66 留批披露图标块行注同族漂移：表行与内联注释中的 `Sa` 图标工厂行号系统性偏 −48
（如 S_ 注 26634，真值 26682 `S_ = Sa(\`arrow-left\`)`）。本批以 Sa 工厂单遍索引
对全树图标块行注做机械个查，收掉 R66 四项留批之一。

## 2. 方法与安全守卫

1. **Sa 工厂索引**：单遍扫双 chunk，正则 `([\w$]+)\s*=\s*Sa\`([a-z][a-z0-9-]*)\``，
   得 名→(行号, icon 串) 表；采纳条件沿用互斥单匹配守卫（名在恰一 chunk 恰一匹配）。
2. **表行个查**（仅注释行）：TABLE 正则 `(?<![\w$])([\w$]{1,4}) ([a-z][a-z0-9-]{2,}) (\d{4,6})(?!\d)`
   匹配「名 icon串 行号」三元组，行号异于索引值则改。
3. **内联注释个查**（全行扫描，`is_comment` 标志区分）：INLINE 正则要求
   `createLucideIcon("icon")` 与 `原 NAME（js N）` **同行共现**，交叉验证后才改。
4. **Fv 碰撞披露**：首版 INLINE 形式误中 MarkdownCodeBlock.tsx:57 `原 Fv（js 18650）`——
   该名是 shiki 的 React.lazy 加载器，不是 Fv 图标。改同行交叉守卫后此碰撞自然排除，
   全批无误纳。
