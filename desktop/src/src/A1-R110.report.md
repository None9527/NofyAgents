# A1-R110 报告：W4 余件——AutomationsMain toast 变体双符（c6/l6）逐字实体化

## 背景

AutomationsMain declare `showToastWithAction`（原 l6，15 消费点）。侦察：束真身极小——c6@138647 锚常量 + l6@138648–138650 包装函数（`m(e, {...t, anchorId: c6})`，m ≡ toast 总入口）。树内 toast canonical = modules/ImeComposition（文件头 import 既有，R48 判例）；ImeComposition toast options 面本含 `anchorId?: string`（@502/515 在案），运行期形状零偏差。

## 方法

1. 双实体逐字落地实体带：c6→AUTOMATIONS_TOAST_ANCHOR_ID、l6→showToastWithAction（混淆局部名 e/t 保留）；`toast` 深依赖即文件头既有 import，无新边。
2. declare 删碑；本地 ToastOptions 接口孤悬随删（唯一引用面 = declare；canonical toast options 面含全成员）。
3. 15 消费点逐字不变（实体沿用 declare 名）。

## 型缝（roundtrip 全剥离）

1. l6 双参 `: any` 注记。
2. l6 次参可选注记 `t?: any`——束 JS 形无可选标记，而树内 15 消费点中 14 处单参调用，TS 必欲可选（运行期 `{...undefined}` = `{}` 语义等同）。
