### 5.2 首启（修复前）—— 捕获 1 处跨 chunk 集成缺陷

renderer 求值无 import-time 崩溃；React 挂载；但 ErrorBoundary 拦截：
`Error: useZCodeIntl 必须在 ZCodeIntlProvider 内使用 at D (IntlProvider-C321H7m8.js:9256) ← _8t (styles-CdEGpc2x.js:212946)`。
**根因**：styles chunk（未重建）的 `useZCodeIntl` 消费 **原 IntlProvider chunk 内部 React context**；boot 入口按 reconstructed 源码供给 **reconstructed I18n 的 context**（另一实例）→ 消费者读空抛错。与 React 同构：凡被未重建 styles chunk 消费的共享实体，必须解析回原 chunk 实例。
**裁决**：非 reconstructed 源码缺陷（I18n.tsx 为 IntlProvider chunk 的字节忠实重建，S4-2 emit-diff 0 差已证；全重建态下本入口接线正确）——属 **hybrid 集成层**问题，修在 boot harness，不动 reconstructed 源。
