# A1-R109 报告：W4 余件——AutomationsMain store 桥双符（qq/T3）改指闭合

## 背景

AutomationsMain 余 store 桥 declare 四员（qq/T3/bX/offPeakStoreStatic）。侦察裁决两收两留：

1. **qq ≡ useModelProvidersStore** = PaymentDeep §11（bundle 78243–78403 逐字，R35 实体化；modules/PaymentDeep 转导出 @319；ModelProviderSettingsSection R35 同判例消费在案）。改指。
2. **T3 ≡ automationsStoreStatic** = stores/automationsStore useAutomationsStore 之 zustand 静面 `.getState()`（UseBoundStore = StoreApi & hook，storeTypes@17；文件头 import 既有）。改指。

## 方法

1. qq declare + 本地 ModelProvidersStoreState 接口删碑；文件头新增 modules/PaymentDeep import（环安全：PaymentDeep 值闭包不达 components/automations，grep 实证零边）；消费点 @782 逐字不变。

3. 改指批非逐字批：无 roundtrip，等价性 = tsc 双口径型面接通。
