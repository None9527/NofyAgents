**型别裁决（均行注志之，禁 any 遵守）**：
1. **interface→type 别名**：PaneWorkspaceScope/PaneBinding/PaneLayoutState/SessionBinding/
   SessionRouterGroup/SessionRouterData/SplitLayoutStoreState（交叉别名）/
   SessionRouterStoreState（交叉别名）/RemoteSessionEntry/PersistableWorkspaceTab。
   理由：消费侧（AppRootLeaves/OnboardingLoginLeaves）以含 `[key:string]:any` 的本地宽松面
   接收 store 态，需隐式索引签名方可流入（R1 WorkspaceTab 同技）。实测确认（/tmp/idx-test.ts）：
   **源侧索引签名不能满足目标侧必具具名属性**（宽松→严格方向不通），故严格→宽松方向
   靠别名隐式索引签名达成。
2. **宽化 `PaneWorkspaceScope.workspaceIdentity: string | null`**（原拟 `string`）：与消费侧
   宽松面及 bundle 空合用法一致；内部读取均经 `?.`/`typeof`/真值防御。RemoteSessionEntry
   同宽化。
3. **泛化（行注宽化）**：`persistableTabEntries<T>`（第二参 Map 值与返回联合数组承本地宽松
   条目面；bundle sEt 对映射值无断言）、`sessionEntryMapByKey<T>`（bundle lEt 仅读 R2 面建键）。
4. **DOM 边界收窄**：`performance.getEntriesByType("navigation") as Array<{type?: string}>`
   （非 any 收窄，行注）。
5. **环安全（头注已证）**：本文件仅被 AppRootLeaves/WorkspaceShell/OnboardingLoginLeaves
   单向引用；依赖方（stores/zustand、WorkspaceTabsDeep、logger、SrcSharedB）均不反向
   import 本文件——已用全树 grep 核验，无成环。
