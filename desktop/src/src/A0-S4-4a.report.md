## 7. 教训（供 S4-4b/c）

1. **declare 闭包要枚举命中行，不要信计数**：U4 起每批都出现"迁出体的 declare 签名引用了未随迁的类型"（U7：ModelProvider/SubagentBadge/IntlShape；U8：OffPeakTaskService/CodingPlanSubscriptionService/ScheduleRule——最后一个藏在**复制的 declare 块内部**，体矩阵完全看不到）。构建前先做**双向交叉普查**：每族导出符号 × 其他族体逐词匹配，可一次抓全。
2. **`declare const` 值不可跨模块值导入**（bundle 期无此导出）：非导出 ambient 值一律按消费方复制；导出型别走 `import type`（擦除，零环）。
3. **§0 运行时常量（图标工厂/testid 串）不可复制**（捆绑会多出一份实现）：共享面留守 + `export` 增补 + 组件 import 取回；前提是组件侧**全部渲染期访问**（箭头函数/JSX 内），初始化期顶层读会触发环序 TDZ。U6/U7/U8 三批验证该模式 emit 中性。
4. **共享 §0 纠缠时，"shim 全留 + 组件侧复制子集" 优于 "shim 摘除"**：U8 shim 1–4947 保持逐字节全同，验证成本一条 `diff` 封顶；复制的 ambient 声明编译期擦除，emit 零痕。
5. **覆盖 harness 的 external 路径转位会出现新旧行数不对称**：esbuild 按源模块逐条发 external import（碰撞后缀区分），且**完全同形的导入行会被合并去重**——旧侧行可能"无声消失"。分类前必须按入口核数（本次 U7 6×(−1+2)、U8 去重合并均已实证），不可直接判语义差。
6. **行号工具链陷阱**：`cat -n` + awk 字段算术会把空行渲染成"数字面包屑"假象（U7 一度误判 §0 含裸数字行）；统一用 `awk '{printf "%d|%s\n", NR+offset, $0}'` 直印。BSD sed `-E` 无 `\b`、无反引用；`$]`/`$_` 在终端包装层会被预展开——正则文件一律经 `write` 工具或 `printf '\044'` 落盘。
7. **跨模块同名组件**（两个 AutomationsMain）合法但要求去向文件名避撞；普查时先查目标目录现有文件名。
8. 通配 external（`--external:*X`）是组件迁深后 emit-diff 仍可比的唯一形态；路径敏感 external 在迁深批次必然假阳性（S4-3 教训，本批全程沿用）。
