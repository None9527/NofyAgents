### 2. getLocalStorage ≡ Be ≡ IntlProvider chunk `a()`

- 束证链：styles chunk 422 行 `import { a as Be, … } from "./IntlProvider-C321H7m8.js"`；
  束内 `q6(e = Be())`@144824 / `KFt(e, t = Be())`@144844 / `kIt(e = Be())`@145194 / `AIt(e, t = Be())`@145208
  即重建体四个持久化函数（loadSidebarTaskPreferences/saveSidebarTaskPreferences/loadCollapsedGroupIds/saveCollapsedGroupIds）的默认参。
- `a()`@6 逐字体：三级 `typeof window < "u" ? window.localStorage : typeof localStorage < "u" ? localStorage : void 0`，
  catch 裸 return——**失败返回 undefined，非 null**。
- 与 QuickPick::safeLocalStorage（iC 形，返回 null）一符一家各保（R121 §3 裁定），本批不合流。
- 分段偏好族（safeWindowLocalStorage ≡ JFt@144852）为另一独立访问器（window-only、返回 null），束内 `XFt(e = JFt())`/`Q6(e, t = JFt())` 实证，不在本批范围，不动。

### 3. 保真偏离发现：bucketTaskDate 的 thisYear/earlier 支

重建体（A0 时代）`bucketTaskDate` 含 `{kind:"thisYear"}`/`{kind:"earlier"}` 两支；
束真相 uPt@140365 无 thisYear 支，末桶为 `{kind:"older"}`：

```
return i >= new Date(s.getFullYear(), s.getMonth() - 1, 1).getTime()
  ? { kind: `lastMonth` }
  : { kind: `older` };
```

i18n 目录实证（IntlProvider-C321H7m8.js）：zh 1492–1499 / en 6010–6017 仅
today/yesterday/daysAgo/thisWeek/lastWeek/thisMonth/lastMonth/**older** 八键，
无 taskTimeline.thisYear / taskTimeline.earlier——重建体的 earlier 桶在运行时渲染裸 i18n id，
thisYear 桶把本应归「更早」的当年旧任务错分。全束排查无其他桶变体（`kind: "older"` 仅 140379 一处）。
修复：删 thisYear 支、earlier→older、比较操作数对齐束内 `i ≡ m6(e)` 归一形（dayStart）。
午夜阈值下归一与原始时间戳比较行为等价（数学可证），此改纯为逐字对齐 + 桶名修正。
