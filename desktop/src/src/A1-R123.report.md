# A1-R123 报告：Sidebar store 桥四符闭合（taskStoreApi 死删 + 三符改指）

## 背景

R121 侦察分层中，store 桥四符（taskStoreApi/getWorkspaceSlice/useTabStore/useOptionalTabStore）
列为实体化层第 ③ 域。本批侦察发现四符全部具备树内既立 canonical（或零消费死声明），
无需束内转录——纯改指/死删批。

  useTaskStore 选择器态 = TaskStore = TaskStoreState & actions，可赋）。
- ko 孤注（jsx 351 设置 store，declare 早前已删）并入墓碑。
