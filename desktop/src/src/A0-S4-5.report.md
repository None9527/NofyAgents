## 10. 教训（供 S5）

1. **esbuild 0.25.12 环境声明链接不对称**：`export declare` 符号经「再导出链」（`export {x} from` 或 import+export 不本地值用）可过门；
   **值引用导入必报 `No matching export`**。跨单元消费环境常量的定式 = 消费侧本地 `declare` 副本（FeedbackCenter L303 先例），零 emit、零新边。
2. **跨 § 前向引用在拆分后显形为导入边**：本批 3 条（u2→u5 值引用、u8→u9 类、u11→u10 环境常量）；迁前跑「段内全部顶层符号 × 他段引用」矩阵可全数预捕（承 S4-3 教训 3）。
3. **执行序必须拓扑化**：依赖件先迁（u5 先 u2、u9 先 u8），shim 再导出块仍按文件序排布；混合态（部分 shim + 剩余原体）
   用 `import {…}` + `export {…}` 对（非 `export…from`），剩余体对已迁符号的引用靠 import 本地绑定解析。
4. **CJS interop 行按覆盖入口数倍增**：services.tsx 图含于 10 入口中的 6 个；每个新 React 消费件净增 ≈6 行 interop。
   累计判定预算式：（新消费件数 − 原位消除数）× 6，本批 24 React + 6 jsx-runtime 全中。
5. **通配 external 别名翻转逐步抖动、累计抵消**：s9/s11 各翻转一次（`X as X` ↔ `X`），批末累计归零 —— 单步残差见别名翻转不必追查，
   以累计白名单恒等式（8 对 90 行）为终裁。
6. **未用导入保留是求值序保险**：shim 逐字保留原导入块（含 3 个迁后未用导入），对首触者入口保序；esbuild 对未用绑定自行丢弃，输出中性（承 4b 教训 6）。
