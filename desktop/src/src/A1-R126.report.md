## 型面精化与型缝（披露）

1. **canonical 入参面精化（WTD）**：gc/vc/yc 束真形仅读注册表三 map，A0 时代 canonical
   注全量 `SessionRegistryState`，与调用面三字段快照不接（SidebarLeaves@262 留批注在案）。
   本批新增 `SessionRegistrySnapshotState`（三字段 pick）并为三符改型；全量 store 态
   结构兼容（字段全具），既有消费面（WTD 内 Hse 链 / PaymentDeep / Sidebar ERt 闭包）全纳。
2. **型缝一（Sidebar@2010/2286）**：本地 WorkspaceTab 无 canonical 必填 kind/label →
   入参 `workspaceTabs as any`（运行时同形）。
3. **型缝二（SidebarLeaves@1481）**：入参 `options.workspaceTabs as any` + 返回
   `as any as WorkspaceTab[]`（下游 sessionScopes 需 workspacePath 必具面）。
4. **型缝三（三处服务映射 memo）**：canonical binding.services 真形 BaseServices（成员可空），
   消费面按原 declare 契据（本地 WorkspaceServices 必具）读 → memo 返回
   `as any as Map<string, {services: WorkspaceServices; remoteSessionId?; isRemoteWorkspace}>`
   复原原契据面（Sidebar@2312 / SidebarLeaves@3136/@3897）。
5. **伪铸销账（Sidebar@2312）**：`baseServices as unknown as WorkspaceServices | null`
   系 A0 迁就旧 declare 伪契据（次参 `WorkspaceServices | null`）之铸；bundle 真形
   useBaseServices 实参直传（ResolvedBaseServices → BaseServices 可赋）→ 删铸还真。
6. **SidebarLeaves stores-core 导入面**：`type BaseServices` 保留——余
   resolveServicesByWorkspaceIdentity declare（@269）仍用（首轮误删致 TS2304，已复原）。
