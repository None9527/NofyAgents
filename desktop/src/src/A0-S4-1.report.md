   （允许纯空行/包装增行）。
3. 其余 → 人工逐 hunk 分类；出现语句级改动即回退。

## §6 教训与范式（供 S4-2…5）

1. **rendererEntry 入口图极小**（仅 9 模块：rendererEntry/SkillStore/logger/
   SrcSharedA/B + out 件）——大部分模块（Home/services/Settings/…）不经它可达。
   单元级 emit-diff 必须用 §1.2b 的 10 入口覆盖束（或按单元消费方扩充入口集），
   否则 diff 空转（cn 单元入口级"逐字相同"即假阴性实例）。
2. **本图 esbuild 输出带 `__esm` 惰性包装**（入口图含 CJS 互操作），模块拆分
   必现包装重组噪声；裸 diff/裸排序 md5 都会误报。判定走 §1.2 三级协议，
   规范化脚本 /tmp/s41-normalize.sh 可直接复用。
3. **碰撞重命名 α-改名**：顶层同名局部（如 `e`/`t`）按模块遍历序加数字后缀，
   单元移动必改后缀——规范化时 `([A-Za-z_$])[0-9]+→\1N` 剥离后再比多重集。
4. **尾单字母 export 块陷阱**：SrcSharedB 尾块以语义名引用绑定，迁移符号的
   shim 必须 `import + export`（制造本地绑定），纯 `export…from` 会使尾块失配。
   SrcSharedA 无此结构（§15 export 块所出符号均留文件内），可用 `export…from`。
5. **私有辅助随消费者迁**：§0 类型脚手架中被迁符号独占的 interface
   （WorkspaceDescriptor）随迁，其余脚手架（ZodInst/ParsePayload/…）留。
6. **树摇对称性**：未被任何活路径消费的符号（如 GHOST_PROVIDER_REF_PREFIX）
   前后束中同被摇掉，diff 中不出现——属正常，勿误判为丢失；但需按 §4 终局
   对照核验"同现同隐"。
7. **既有缺口的 external 隔离**（3 懒 chunk + MarkdownVendored +
   UsageStatsUiParts）是 S3b 已立范式，前后一致施用即不损 diff 效力；
   npm 一律真实解析。
8. **操作工艺**：sed 行块抽取 + diff 回验（块级逐字）+ 区段偏移回算复核
   （本批两次 off-by-one 均被该区段校验捕获）；迁移前先备份原文件于 /tmp。
9. **git HEAD 是天然对照基线**：覆盖束的 HEAD 态快照用 `git show HEAD:<path>`
   临时换入获得（勿 commit/stash，防中断风险）。
