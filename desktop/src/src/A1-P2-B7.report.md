```ts
export interface WebRemoteSwitcher {
  listWorkspaces(): Promise<WebRemoteTaskIndex>;        // WebRemoteTaskIndex.workspaces: WebRemoteWorkspace[]
  onWorkspaceListUpdated?(cb: (result: WebRemoteTaskIndex) => void): () => void;
```

（null 支，tsc 实测链首）；(b) MobileHomeResult 余面 activeWorkspaceKey/activeTaskId（可赋，非阻塞）；
(c) updateMobileViewState 返回 `Promise<unknown>` vs `Promise<void>`（协变返回，潜在第二失配点，
tsc 链首报 (a) 即止）。A0-CLEANUP4 已对齐 kind 面（SidebarLeaves @3325 注在案：「供 listWorkspaces 返回面
双向可比」），workspacePurpose null 支为其遗留。两叶均非本泳道属主 → 留批 + §六 跨域申请。
