# Agent 开发手册文件说明

本目录提供 CLI/MCP 实现版使用说明和机器契约。可执行入口为 crates/common/nofy-cli，入站 MCP 位于 nofy-agent-mcp；两者共用 nofy-agent-client 与 nofy-agent-project。前端暂停，实际验收范围由记录文件逐项标注。

| 文件 | 职责 |
|---|---|
| README.md | 阅读入口、实现状态、概念、当前宿主可用入口 |
| cli.md | 全局参数、工程/Agent/模块/系统/运行/会话/资源命令、例子、返回码与排错 |
| modules.md | 原生 ModuleKind、插槽/依赖、三种接入方式、完整纯计算工具及外部执行前提 |
| sessions.md | SessionPolicy 规则/源码模块、会话实例、20 项 CLI/MCP 输入、版本、生命周期与恢复边界 |
| mcp.md | 内核控制 MCP 的接入、发现、调用、资源、错误、事件、取消和 Codex 配置 |
| protocol.md | 源码草稿到原生声明的转换、公共信封、版本精度、幂等、权限及验收规则 |
| operations.json | 注册操作、CLI/MCP 名称、参数与结果 Schema、状态及内核映射的机器索引 |
| contracts.schema.json | 公共开发协议的类型、操作输入和结果对象；NativeJson 不替代原生 DTO 校验 |
| http-api-index.json | 由当前 Host API 路由源码提取的真实方法、路径、来源和行号；包含已经注册的源码工程路由 |
| assembly.md | MCP 自描述装配、公开参数、原生正文编码、精简结果和实际验收 |
| repositories.md | 版本化模块仓库、固定摘要引用、装配/卸载、源码导出 |
| process-sessions.md | 无 cgroup 执行、交互管道/PTY、stdio MCP、受控网络代理 |
| session-branches.md | fork/rewind/tree、来源证明、历史边界与不重放效果 |
| permissions.md | allow/deny/ask、命令分析、范围审批记忆与撤销 |
| agent-collaboration.md | 父运行拥有的异步子任务与根内消息 |
| human-and-escalation.md | Human 待答模板、精确答复、已结算失败后的显式升级 |
| model-resilience.md | hosted 工具透传、图片/溢出恢复、压力/手动压缩与原重试阶段 |
| input-queues.md | steering/follow_up、all/one_at_a_time 与原输入回执 |
| cleanup.md | 工程/声明删除、配置移除、模块 yank 与孤儿源码回收 |

用户业务依赖由用户安装，手册与源码包不附带运行库或秘密。[0.1 文档记录](../verification/agent-development-handbook.md)与[0.2 Session 设计记录](../verification/session-modularization-design.md)及其 JSON 保存各自检查范围、结果和边界；原始记录另存工作区外。不把文档检查说成业务测试或完整平台验收。

新版实现证据见 [CLI/MCP 记录](../verification/agent-development-cli-mcp.md)和[Session 记录](../verification/session-modularization.md)，早期设计检查保持原版本和范围。
