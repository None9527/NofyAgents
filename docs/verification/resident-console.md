# 常驻控制台功能块验收

L4 交付独立 console 源码目录，通过同一 Rust Host 的 --console-dir 装载。页面、声明文件和 API 使用原 ControlPlane、Loader、Supervisor 与持久状态；没有第二份配置数据库或执行循环。常规界面修改刷新读取磁盘，模块修改仍经草稿、发布及显式应用。该验收关闭本块功能基线，不关闭完整状态迁移、记忆职责与 embedding、多套锁定参考版本预设及最终发布。

## 施工与影响范围

依用户要求，整块实现、接入、文档和用例完成后集中验证；失败集中修复，仅补验受影响项。入口影响分析及补充结果保存在 /tmp/nofy-console.il8cpqrp/impact*.json，router 为 CRITICAL，33 个直接、36 个总影响对象；编辑前已报告。目录服务、作用域查询及预算投影分别补充分析，新符号的索引缺边不作为低风险证明。

生产 Rust 范围为 Host 的 lib.rs、main.rs、api.rs、auth.rs、loader.rs、新增 console.rs 与 api/budgets.rs，以及 Runtime 的 governance.rs 与新增 governance/view.rs，共 9 份。原 require/check、运行协议、模型调用、预算结算、调度与状态表不改。新增 /api/v1/access 复用原授权判定，/api/v1/budgets 只读宿主原预算摘要；观察不开户、不推进时钟、不更换限额、不结算预留。目录服务在本轮 Linux 实际验证，其他平台明确拒绝开启。

源码包和普通依赖清单边界保持，外部依赖继续由用户安装；没有新增前端依赖、解释器或依赖安装门槛。静态请求的有界读取不是源码打包配额。
