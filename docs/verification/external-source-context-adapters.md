# 默认外部来源与上下文程序验收

L3c2 交付默认 Host 的 `tool_source.http` 与 `context.programmed`。两类能力通过声明装载，复用原 HTTP 资源、隔离代码执行器、权限/预算和模型恢复日志；普通模块更新沿 live/v5 生效。源码包及外部依赖边界未变。

## 实际能力

| 范围 | 证据 |
|---|---|
| 动态工具源 | 实际 GET 读取目录和 Schema；本地版本绑定连接、配置及外部版本，POST 携带原版本调用；旧版本被服务拒绝时不执行新效果 |
| 资源边界 | 编译不联网或读取凭据；路径、方法及凭据引用保持连接授权，超时和取消不启动业务效果 |
| 上下文程序 | 默认 Host 通过原隔离 code worker 执行外部 plan、prepare 和 finish；纯转换无需模型，脚本不能伪造 token 用量 |
| 模型压缩 | 使用显式模型及原 pending context 的 operation_scope，经统一 sample_model；实际响应进入上下文，模型用量计入原账本 |
| 当前回合 | System 和当前输入不能被删除/替换；新增策略尚无原回合边界时，保守保留整个非 System 历史 |
| 配置更新 | 实际 API/Worker 在同进程替换工具源与上下文策略、回滚并继续原会话；强制权限仍可拒绝新工具，已成功的旧工具不重做 |
| 硬退出恢复 | 治理和无治理两种模式各执行一次 `exit(71)`，通过原模型票据对账后继续；原采样请求不重发，原工具一次 |

Host 新增 5 个测试入口，含 1 个条件子进程助手；父测试实际覆盖 3 条更新/回滚/权限流程、2 条采样硬退出恢复、1 条正常压缩及 2 条坏更新拒绝流程。协议服务使用实际回环 HTTP/SSE 和隔离 helper；本阶段没有调用真实外部模型或读取生产凭据。

## 失败与修正边界

初始构建发现适配器调用的 `await_resource` 和 `model_journal::enabled` 仍为跨包私有。补充 HIGH 影响分析后开放这两个既有只读/等待辅助接口，函数体、私有能力类型和执行语义保持；未暴露日志构造或原始调度权限。

新权限用例的强制清单遗漏自身 `after_effect` Hook，导致 `after_tool` 收到不允许的 Deny 决策。仅补齐夹具内该 Hook 工具许可，新业务工具仍被拒绝；生产权限未放宽。

原硬退出预算用例出现 `run already leased` 后，解除停驻回执在 15 秒等待内未完成。默认所有者租约为 30 秒，且子进程可以在看到已提交回执、尚未释放围栏时退出；该恢复用例原有 update/resume 已使用 45 秒等待。只将此 hard-exit 用例的 unpark 等待对齐到 45 秒，并记录实际等待，生产租约、重试、默认 API 测试等待均未改。补验四条退出流程的回执均为 56–159 毫秒，没有再次观察到残留租约；保留初轮超时，不将此次补验宣称为生产调度性能修复。
