# L3b4：同资源预算额度迁移验收

后续L3b5已补预算暂停后保留未派发模型/工具并原位继续的边界，实际默认Host、硬退出、未知效果和完整回归见[后续验收](budget-resumption.md)。下文保留L3b4阶段事实与当时未完成项。

在同一已确认停驻的根 Agent 中，原 `update_modules` 可显式选择 `budget_limits`，从已发布配置更新额度和重试策略，继续使用原账本。用量、预留、回执和会话预算不归零；更新不需要重编译或重启宿主。本阶段没有完成额度耗尽后的待派发工作边界，也没有完成全部状态迁移。

## 实现与范围

`governance::BudgetLedgerBinding` 记录治理引用、当前 Profile、原账本、资源及历史身份。私有迁移计划在事务外解析并验证源目标 Profile；原根租约、停驻与 CAS 校验后，原账本修改、live/v4 版本及管理回执在同一事务提交。没有增加数据库表、依赖或执行循环。

治理引用、工厂、依赖及宿主安装资源保持；目标 Profile 须属于同一资源与根 SQLite 存储，原宿主上限继续约束配置。其他未选择能力的共享依赖仍受保护。配置可通过治理工厂映射为 limits/retry，不按产品名或特定工厂配置字段分派。完整契约与 Schema 见[预算迁移契约](../architecture/live-budget-transitions.md)。

| 变化 | 实际语义 |
| --- | --- |
| 增加/缩减额度 | 保留 used/reserved/active/operation_count；可将限额降到既有用量以下，后续派发被阻断 |
| 旧预留 | 尚未 claim 的预留重检新额度、深度及对应活动限额；已 claim 的意图保持 uncertain，可继续结算；成功回执可重放 |
| 期限 | 显式 duration 从原 created_at_ms 起算，其他额度变化不重设期限；时钟单调 |
| 阻断 | 新额度可解除额度型阻断；actual_usage_exceeded_reservation 等完整性事实不清除，历史事件保留 |
| 子调用 | 原和中间版本 Profile 通过历史别名回到原账本，继承最新规格和重试策略，不再开空账本或安装陈旧限额 |
| 会话/历史 | 种子保留绑定及会话原预算根；后续 Prompt 更新不丢失映射，已关闭历史根的重放不改写当前额度 |
| 回滚 | 显式产生新版本，保留已花费额度；没有预算退款或副作用重发 |

生产改动为 Runtime 的 12 份既有文件及新增 `supervisor/jobs/managed/transition/budgets.rs`：governance 的 Profile/继承/账本事务、Agent 治理句柄、受管转换/证明/会话归属及引用读取。另修改两处测试注册、新增三份测试文件。具体字节摘要见[结构化结果](live-budget-transitions.json)。

## 风险与失败记录

编辑前已对治理、预算派发、转换、恢复、会话及引用读取集中做 upstream 分析并报告 CRITICAL。图谱对 Rust 字段/别名边不完整，`claim`、`sqlite.rs` 等同名项曾选到其他领域，已按精确源路径和实际实现补证，不能用 LOW/0 判定无风险。

最初 Runtime 全目标类型检查通过，49.780 秒。首轮测试编译误用了与预算事件同名的 `SqliteStore.events` 固有方法，改为明确调用 `BudgetStore::events`，没有改变生产逻辑或断言；编译失败保存在 `attempt-1/parking-build.*`。随后第一批八项通过，4.446 秒；补齐共享依赖与活动准入边界后十项及最终完整矩阵通过，未出现功能测试失败重跑。

本阶段使用确定性本地模型和真实 SQLite、HTTP、helper/进程恢复验证契约，未新增真实上游模型验收。普通源码包、依赖清单及用户自行安装依赖的边界不变，没有环境/版本/摘要打包门槛或包体配额，没有 commit/push。

测试终结后，首次默认并行索引因 `malloc(): unaligned tcache chunk detected` 崩溃，元数据未更新，失败日志与索引文件已备份。仅对该索引进程设置一个解析 worker 后，完整重建通过，18.1 秒；未修改业务源码或已安装工具。不能据此判定崩溃根因已经修复。新索引 695 文件、13545 节点、35788 边、604 社区、300 流程、embedding 0，实际图查询核对文件/节点数。

最终 `detect_changes(all)` 为整个累计工作树映射的 10772 文件、2647 符号、198 受影响流程、CRITICAL，已报告；本阶段 13 生产源码及测试范围另由精确清单、摘要与实际回归证明，不将累计数当新增量。AGENTS 只更新索引统计行，规则正文保持。
