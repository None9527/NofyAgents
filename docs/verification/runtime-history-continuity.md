# L8 运行库业务接续验收

本块列出的业务矩阵通过，整体目标仍 active。实际交付包含一处模型生命周期修复与五个新增 HTTP 行为用例；只完成数据搬移的 L7 通过证据不能代替本块。

## 根因与修复

迁移 quiesce 调用 `Loader::drain_model_workers`，原方法在排空前取消模型停止令牌。该令牌是 Host 接纳令牌的 child，取消后永久拒绝模型评估，并不反向取消其他 Loader。规划、准备、提交、撤销均可能走这条路径，导致随后需要模型的会话、审批续行及模型对账后续变成 `Cancelled`。

生产只改 `crates/common/nofy-agent-host/src/loader/models.rs` 的这一方法：取消冗余的 child 停止信号，继续等待实际评估许可并退休缓存进程；下一步模型调用可重建评估进程。真正的 Host shutdown 仍先取消父令牌，原关停链等待子进程回收。没有修改 Runtime 状态、租约、预算、票据格式、接口、依赖或模型声明，也没有重置停止令牌或新增主循环。

精确生产差异见外部证据目录 production.diff；修改前该文件与 L7 冻结摘要一致，修复前源码已归档。其余生产 Rust 源码与 L7 一致。

## 实际验证波次

| 波次 | 结果 | 处理 |
|---|---|---|
| 完整用例与文档收齐后的首次构建 | E0583，三个子模块路径声明错误；未执行行为测试 | 集中修正路径并保存可按原冻结 SHA 复核的失败源码 |
| 首次行为波次 | 9 项中 6 通过、3 失败 | 三个失败均在迁移后期望 completed、实际 cancelled；据此定位生产排空误停止 |
| 集中生产修复后的迁移补验 | 9 通过，188 其它 HTTP 项过滤 | 所有迁移调用都经过被修方法，包含新增 5 项与 L7 直接相关 4 项 |
| 模型真正关停与生命周期补验 | 2 通过 | 验证实际丢弃、取消、排队、进程回收，以及用户取消与断开流的原路径 |

最终本块新运行 11 项相关检查通过；这不是一次全工作区全绿，也不把 L7 的 718 项重复记为本轮执行数。修复后的完整 HTTP 测试入口共有 197 项，本块只运行受影响范围。6 份阶段 Rust 文件统一格式检查通过，704 份验证输入在波次内摘要一致。

## 直接业务证据

| 场景 | 验证事实 |
|---|---|
| 会话、队列与预算 | 原首轮已完成、后两轮已排队时实际搬移；第二轮继续读取第一轮，第三轮仍受原两次模型额度阻断。反向后原 session、输入/轮次游标、创建时间、绝对期限及共享预算根保留，重试未再请求模型 |
| 审批、邮箱与取消 | 原模型请求已生成待审批工具调用；两条插话进入原地址。跨库后拒绝篡改调用、原审批成功，效果一次、两条插话按 FIFO 进入后续模型并标记 delivered。另一原运行的持久取消 sequence 和未消费状态在搬移前后相同，恢复后取消先于工具效果生效 |
| 未知根工具 | 无预算/有预算均在 HTTP 效果已发生后实际 exit 97，按原租约期限等待。原 Supervisor 确认待对账后，恢复命令先接纳，再搬库并由原 Worker 执行；原调用证明及预留不变、效果一次、反向后原命令只回放结果 |
| 未知 Hook | 无预算日志/持久预算均在 before_stop HTTP 效果后实际 exit 76，原票据写入后保留。已接纳命令、原事件与存储/作用域证明跨库继续；原模型和 Hook 各一次，预留结清，反向后回执相同 |
| 未知模型 | 根/工作流子 Agent 各覆盖普通预算和无预算日志，共四组合。在原请求已到达、未返回时实际 exit 97；原票据、generation、请求和作用域及预留不改，权威对账命令先接纳再搬库。原请求一次，随后正常 HTTP 效果一次；普通预算保守结算原 claim，反向后历史与回执相同 |
| 模型生命周期 | 规划被拒绝、准备撤销、正向/反向提交后停止标志保持 false，后续真实协议请求继续；真正 shutdown 后停止标志为 true 且评估 PID 清零，原在途取消与回收用例也通过 |

全部迁移产生不同物理 generation，保留逻辑身份；每次退休源库的业务清单仍等于原计划。未知效果没有先结清或清空预算再搬移，恢复命令是搬移前已经接纳的原命令；没有直接改写租约、扩大额度、重置 session 或伪造新运行取代原工作。

这些模型服务与权威对账输入是本机协议/恢复夹具，不是训练模型或用户上游的响应验收。本块真实用户网关请求为 0，既有 high/n 名称差异、上游身份与 256k 上下文均没有新确认。UI 未变，未重复浏览器或中文字体验收。
