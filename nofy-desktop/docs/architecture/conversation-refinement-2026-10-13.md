## 呈现与组件所有权

- `features/conversation/activityModel.ts`：把已知工具语义与真实状态转为摘要；未知状态不推测成功。命令优先于工作目录；路径可以包含 Windows 分隔符。
- `features/conversation/ActivityCard.tsx`：摘要、单层终端、差异片段、技术详情。命令保留换行；输出复制完整原文，预览限长。
- `features/conversation/Spine.tsx`：保持事件顺序、搜索锚点与虚拟行边界；分别组织活动组和正文。
- `ui/disclosure.tsx`：继续统一控制手动选择、自动开合、键盘语义与折叠动画。
- `ui/contentActions.tsx` / `ui/highlight.tsx`：共享复制反馈和语法高亮，未复制另一套底层实现。
- `ui/foundations.css`：活动正文 13px、辅助 12px（随基础字号变化），72% 前景混色、3% 内容表面；明暗主题共用语义值。
- `ui/conversation.css`：唯一的对话呈现样式所有者。成功不铺色；错误仅突出对应状态；展开详情和摘要分层；不靠缩小图标获得窄栏空间。

文件差异使用真实 ACP 片段；增删符号独立对齐，代码复用语法高亮，避免 block span 与换行叠加出双倍行距。这里仍是操作片段预览，不是全工作区 Git 差异，也不意味着待执行操作已经落盘。

## 验证方法

1. 类型、样式所有权、架构边界与单元测试。
2. 隔离 ACP 事件流驱动实际 Electron：运行、完成、失败、状态未知、编辑片段、手动开合、键盘搜索揭示、280px 压缩与悬停复制。
3. 逐帧测量折叠的打开和关闭；减少动态效果时不执行过渡。
4. 明暗主题截图，检查文件差异/终端面板、摘要宽度、代码行高和横向溢出。
5. 一万条内容、动态折叠、流式跟随、历史阅读锚点、会话切换与隐藏恢复回归。

证据目录与最终结果见同目录 `conversation-refinement-2026-10-13-evidence.json`。GUI 事件来自隔离的合成 ACP，不能作为真实模型调用恢复的证据。

## 保留的边界

本轮没有添加没有服务契约的点赞上报、语音朗读、全局补丁撤销或伪造耗时；也没有新增一个独立 UI 组件库。完整工具注册渲染器、摘要播放队列等参考能力需基于后续真实工具类型接入，避免以大量占位 UI 代替可用功能。
