# Codex 中栏：第一批呈现机制落地

日期：2026-10-13。依据 `codex-center-system-research-2026-10-13.md` 和对应安装包证据。本批完成活动摘要、两层折叠协作、滚动意图、回答空间的贯通改造；不是整套 Codex 中栏迁移完成。

## 状态与职责

| 所有者 | 本批职责 |
| --- | --- |
| `workflowModel.ts` | 区分 working / responding / settled；划分普通历史、答案、持续可见错误与确认项 |
| `rollingSummary.tsx` / `summaryTiming.ts` | 保留现有组件接口；同 key 原位更新、换 key 最小驻留 1000ms、仅保留最新待显示状态、完成立即更新 |
| `WorkStage.tsx` / `ThoughtActivity.tsx` | 只给当前收起摘要提供活动反馈；展开明细时停止摘要扫光 |
| 共享 `Disclosure` / `CollapsibleRow` 与 CSS | 沿用原生语义和稳定 DOM；打开 300ms、关闭 150ms，可中途反向；减少动态效果时取消几何动画 |
| `useTranscriptScroll.ts` | 唯一 DOM 滚动所有者，协调恢复、跟随、几何变化、用户中断、点击位置补偿和回答空间 |
| `transcriptViewport.ts` | 纯状态转移与空间预算，不读取 DOM、不依赖内核 |
| `Spine.tsx` | 把呈现阶段、用户意图、虚拟列表及共享视口控制器连接起来 |

未增加第二套组件库，没有修改内核协议。沿用现有阅读宽度和窗口骨架。

## 可观察变化

- 摘要不再轮播旧命令，没有上下滚动的出入文字副本。同一摘要的文本节点持续复用。
- 当前活动延迟 600ms 后强调约 1 秒，之后静止约 3 秒；展开组、展开工具、已结束轮次和隐藏历史均停止扫光。
- 整轮历史和工具明细保持独立开关；用户手动选择仍优先于后续默认状态。失败、取消、待确认工具不会随普通历史一起隐藏。若一个工具组含这类项，整个组的摘要保留。
- 展开/收起时，视口控制器对点击位置补偿 350ms；滚轮、触摸、指针和键盘输入可中断控制。
- 新提交（包括新会话的第一轮）建立有上限的回答留白：`max(0, min(height * 2/3, height - 240))`。增长消耗空间，上滚也消耗空间；窗口缩小重新约束上限。
- 短内容先观察，溢出后跟随；上滚阅读不会被 token 追加抢走位置。点击“回到最新消息”重新进入明确跟随。
- 虚拟列表继续由原有测量、阅读记录和离屏导航机制管理。

## 协议边界与后续工作

内核 `response_completed` 只是单次模型响应结束，后面可能继续工具调用；当前块没有显式的 `commentary/final_answer` 标记。因此 responding 仅表示正文正在显示，**不表示最终回答开始**。本批不会用它提前收起历史，普通短正文继续观察到溢出。整轮结束后才使用现有保守规则确认尾答案。

仍待后续批次：显式最终回答语义贯穿协议和历史回放；增量 Markdown 稳定片段与流式尾部解析；消息导航轨、完整回答操作与产物能力。真实模型“卡住”的网络、模型工具参数及内核运行问题不由本批呈现测试证明已修复。
