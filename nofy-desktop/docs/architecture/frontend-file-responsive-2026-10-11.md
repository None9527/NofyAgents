# 文件预览自适应与操作精简（2026-10-11）

用户反馈上轮“⋯”中的刷新、关闭多余，文件页面未正确自适应。确认两处具体原因：文件源码默认关闭换行；≤500px 文件区使用绝对定位目录抽屉，覆盖大量正文。源码行号的 inline 前缀也不适合续行。

## 当前实现

- 去掉文件工具条整个“⋯”入口及其刷新/关闭工作区动作。标签上的关闭与双击固定保留，文件监听沿用原有自动更新。Markdown 模式切换始终可用，小栏变成带 title 的紧凑按钮。
- 文件树回到并排布局，随宿主收缩并为内容预留至少180px；不再用覆盖式抽屉。宽栏继续支持拖拽和独立宽度偏好，折叠后正文占满可用宽度。
- CodeBlock 增加可选 defaultWrap，默认 false，只有文件源码启用。可手动关闭换行；续行保留行号 gutter，横向滚动只在关闭换行时需要。
- 预览 viewport 具有 min-width:0；源码/Markdown 内边距随可用宽度变化；Markdown 图片受内容宽度约束；独立图片预览同时受 viewport 宽高约束。
