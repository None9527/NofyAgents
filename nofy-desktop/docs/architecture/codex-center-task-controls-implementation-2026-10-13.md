# 中栏任务控制与概览：A 批实施记录

本轮落实整体复核方案中的 A 批。对应参考资料为 `codex-center-integration-audit-2026-10-13.md` 及其本地 Codex 包证据索引。

## 交付边界

中栏右上方现在并排提供两个不同入口：

- 会话操作：重命名、置顶、已读状态、本地分组、分叉、导出、复制工作区路径、归档、删除。运行中不能分叉、归档、删除；分叉和删除在执行前再次校验状态。失败保留在操作对话框中，支持重试。
- 任务概览：工作区 Git 变更、当前任务的子智能体、已加载内容的文件来源。点击打开既有审查、子智能体和文件工作区；添加文件进入下一条消息的附件草稿，不伪装成已发送来源。

概览支持章节折叠、来源展开、按会话保存固定与章节偏好。300px 概览根据实际中栏宽度在弹层、正文让位、阅读轴外留白三种模式间切换。固定卡片随内容收高；低矮窗口中的弹层限制在输入区域上方并允许滚动。280px 中栏保留两个任务入口。修复折叠导航的透明容器残留点击区域、遮挡会话菜单的问题。

## 状态与复用

- `application/workspace/useTaskOverview.ts`：会话级偏好和暂时可见状态；不向内核写窗口状态。
- `application/workspace/taskSources.ts`：保留并去重结构化附件/工具文件引用；忽略普通流式文本变化对概览快照的影响。文件跳转复用既有 fileWorkspaceOwner 和缓存。
- `features/shell/sessionCommands.ts`：侧栏与头部共享组织命令及运行约束。
- `features/shell/TaskOverview.tsx`：汇总章节与详情路由；不写滚动位置，不创建第二套文件、Git 或 Agent 状态。
- `ShellLayout` 与 `ui/taskOverviewLayout.ts`：布局模式和空间预算。
- 复用 MenuButton、Dialog、Disclosure、Btn、AnchoredPopover、tokens。共享菜单仅增加可选章节分隔；Popover 增加向下定位、焦点和避让区域能力，既有上下文浮层保持默认行为。
- Git 查询失败保留为 error，不再返回 null 冒充无变更。

## 仍未完成

本轮不是整套 Codex 中栏完成声明。B 批的持续计时、按回答分叉、按回合 Hook 统计、工作过程折叠和状态反馈仍需独立完成闭环；C 批的表格边界、滚动/输入整体联动仍保留。会话菜单里的分叉是整个会话分叉，不等于按旧回答截止点分叉。

来源目前只纳入已加载协议中明确给出的本地附件引用及绝对路径 locations；未加载历史、网页来源和文本中猜测的路径不计入。Git 显示工作区当前未提交变更，不声称是本轮产生的变更。侧聊、调度、分享、新窗口等未接通的能力未伪装为可用命令。
