# 对话主页 H1–H4 Implementation Plan

Goal: 落地已批准的 ZCode 对照方案，统一主页布局、阅读记忆、dock 状态与消息层级。
Architecture: application 保存会话阅读与输入语义；ui 负责尺寸、滚动和 modal 宿主；feature 组合现有客户端，内核继续独立。沿用现有 dirty checkout，保留无关修改，不自动提交。
Tech Stack: React 19 / Electron / TypeScript / TanStack Virtual / ACP。

- [x] H1：共享 conversation-column 样式、空间决策纯函数、split/sheet 宿主；桌面880–1920与侧栏宽度联合验收。
- [x] H2：按runtime/session保存阅读anchor、offset和following；UI处理resize、恢复与回到最新；真实切会话与虚拟列表回归。
- [x] H3：审批与composer共用dock且保留草稿；附件-only提交与busy输入按真实协议处理；失败保留草稿、queue admission与完成分离。
- [x] H4：自然宽气泡、统一行边距、稳定过程摘要、历史不执行入场动画；保留hook排除与有序工具呈现。
- [x] 验证：pnpm verify、主页联合GUI、历史虚拟化/工作区/审批与设置回归，性能三次门；打包隔离profile验证并重启新版。
