# M1 项目、草稿与导航契约

目录选择与导出属于 main 宿主能力，经 typed preload bridge 暴露。取消目录选择为 null，取消保存为 false，均不触发内核请求。目录必须为绝对、可访问目录；导出路径仅取系统保存对话框的结果。

窗口所选项目和最近项目由 workspace 偏好层保存。会话 cwd 来自内核；每次新建取所选 cwd，不修改已有会话目录。当前会话与未创建会话的草稿分别用 session/project 身份隔离，附件归同一草稿。

发送失败保留内容；发送成功仅清掉该次提交的同一版本，期间新输入不会被清掉。重载恢复最后会话，失败后只尝试一次新建。异步导航采用最新意图序号，旧 load/new 的结果可入库，但不能抢走当前选择。

IPC 新能力：pickDirectory、saveText。exportFileName 去除目录段；文件保存仅写用户选中的目的地，不提供 renderer 任意路径写入口。
