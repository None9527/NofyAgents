# Reusable main-agent component repository

`module-repository.json` is the source repository index. It is consumed by the existing `ModuleStore`; it is not the trusted runtime `ModuleRegistry` and does not install code or grant authority.

The repository contains 15 independently versioned packages:

- Foundation (7): context compaction (`context-compaction@0.2.2`), bounded skill task, plan, collaboration, Human question, execution escalation and resilience.
- Main-agent (3): inherited root guardrails/shared budget, bounded delegate, declaration-driven assembly.
- Model (3): frozen Chat Completions (`model-chat-completions@0.1.0`), OpenAI Responses (`model-responses@0.1.0`), and Anthropic Messages (`model-messages@0.1.0`) protocols with explicitly configured connection/model.
- Workspace (2): bounded workspace file tools/rules/cwd (`workspace-files@0.2.0`) and confined command execution (`workspace-command@0.1.0`, supporting both `resource.process_tree_limits` and `resource.process_namespace_limits`).

Register the source with `nofy repository add nofy --host-directory /absolute/path/to/modules`, retain the returned revision, then explicitly synchronize with `nofy repository sync nofy --expected-revision <returned-revision>`. These are host management operations requiring the existing resource/edit scopes. They are not performed merely by building a source project. Query `nofy schema --input` using a package coordinate to obtain its parameters, ports and exports, then use `agent.module.use` to pin it.

`presets/omni` contains the self-contained `omni@0.1.0` source generated by `omni_preset`, importing workspace, model protocol, foundation, and main-agent packages as digest-pinned frozen sources under `.nofy-module-packages/`. It builds offline once non-secret provider configuration is supplied; source packages can be exported independently of this repository. Rebuild the source with the public-API example documented in `docs/manual/omni-agent.md`.

Versions are immutable in ModuleStore. Do not edit an already published package in place: publish the next version and explicitly replace the import. No remote repository is created and no source is uploaded by these files.

Protocol files in `models/chat-completions`, `models/responses`, and `models/messages` are byte-for-byte frozen copies of the existing coding preset protocols at this source revision, distributed under the repository license. Each package stores only source and credential references, never secret values.
