# 通用 Agent 能力包

context-compaction@0.2.0 增加 manual_prefix，默认 /compact，以 Session 新轮输入显式汇总旧历史；空字符串关闭手动入口。自动阈值模式保留。模型溢出时的尾部保留另由内核可选 model.context_fallback 提供，不将省略旧视图伪称为摘要。

module-repository.json 登记独立源码包。context-compaction/compact.rhai 使用 context.programmed 的 plan/prepare/finish 协议实施阈值驱动压缩，阈值采用文本视图字符数除以四的估算，不宣称精确 tokenizer；保留当前轮次、系统消息与工具配对，模型采样由内核持久回执和预算持有。导出的 journal 挂在 bindings，policy 挂在 context_policies。agent-task 使用 tool.skills 的声明执行绑定创建可恢复子 Agent，model/tools 端口由调用方提供；它是同步子结果工具，与通用异步任务通信分别管理。plan 是真实校验并返回计划的工具，状态由原运行事件和消息持久化；需要读取当前计划时使用本运行最近一次成功 update_plan 结果。每个包只有源码及显式清单，不安装外部依赖。

agent-collaboration 将明确的 children 工具包接入 resource.agent_tasks，导出分别挂到 bindings/tool_packs 的 binding/tools，以及可同时装在父子 Agent 的 messages。父运行持有后台任务，预算和恢复仍由原运行树负责。

ask-user 通过原 Workflow Human 节点持久问询；execution-escalation 在明确结算的普通失败后取得匹配的人类答复，再使用声明的另一工具包。resilience 仅接线已有 stage.length/stage.repeat 与 runtime.recipe，recipe 导出挂到单个 recipe 插槽。所有包入口为各目录 module.json，source-files.json 列明源码文件。
