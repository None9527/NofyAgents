# 声明式 embedding 协议

embeddings.rhai 和 parameters.schema.json 是原 model.programmed / resource.model_protocol 的外部源码制品；通过既有连接发出 JSON embedding 请求，严格恢复响应 index 顺序、数量、维度、有限非零向量及真实 prompt-token usage。source 的 purpose 参数区分文档和查询，默认协议不向远端增加专用字段；需要不同提供方协议时编辑本源码并发布新的制品，不修改 Rust 内核。context.memory_semantic_connected 使用同一预算、模型日志和恢复票据；源码中没有密钥、依赖安装或原产品宿主。

本轮实现、接入、文档及用例全部收齐后集中验证，相关1012项最终通过；首波失败与定向补验见 docs/verification/semantic-memory.md。此协议的显式文本数组/向量数组契约适用于 embedding，不能当作自然语言聊天协议。实际外部提供方的模型/维度与使用前提由连接声明提供，不因本地回环用例而宣称已覆盖真实上游推理。

协议按共享接纳契约预留 1 个输出 token 上界，完成时按真实 0 输出结算；请求上界为一次。该值不是模型响应实际用量。
